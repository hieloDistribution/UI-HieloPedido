# REGLAS DEL PROYECTO

## Gestión de Git y Subidas (Regla Estricta)
* **Prohibición de auto-push:** El asistente NO debe ejecutar comandos de subida a Git (`git push` u operaciones de carga automática) por su cuenta bajo ninguna circunstancia.
* **Consentimiento Explícito:** Solo se deben ejecutar subidas o comandos de push cuando el usuario lo solicite de forma explícita en su mensaje (ej. "subí a git", "hacé push", "subilo ahora", etc.).
